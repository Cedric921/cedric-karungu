This is a professional React portfolio website built with:
  - React 19.2.3 (UI framework)

The project is organized following React best practices with:
  - Clear separation of concerns
  - Scalable folder structure
  - Barrel exports for clean imports
  - Path aliases for cleaner code
  - Single source of truth for all code

                   6. HOW EVERYTHING WORKS TOGETHER
=================================================================================

Application Flow:
═══════════════════════════════════════════════════════════════════════════════

  1. index.html (loaded first)
     └─ Contains <div id="root"></div>
     └─ Loads src/index.jsx

  2. src/index.jsx (React entry point)
     └─ Imports React, ReactDOM
     └─ Imports src/styles/globals.css (Tailwind CSS applied here!)
     └─ Imports src/App
     └─ Renders App component into #root

  3. src/App.jsx (Root component)
     └─ Manages theme state (dark/light mode)
     └─ Manages scroll state (for scroll-to-top button)
     └─ Renders all page sections in order:
        ├─ Navbar (theme toggle, navigation)
        ├─ Hero (landing section)
        ├─ Skills (technical skills)
        ├─ Portfolio (projects)
        ├─ Experience (timeline)
        ├─ Contact (contact form)
        └─ Footer (footer)

  4. Components (ui building blocks)
     └─ Navbar.jsx
        ├─ Uses: Icons from @constants
        ├─ Receives: theme, toggleTheme from App
        └─ Renders: Navigation bar with mobile menu

     └─ Hero.jsx
        ├─ Uses: Icons from @constants
        └─ Renders: Landing section with CTA

     └─ Skills.jsx
        ├─ Uses: SKILLS array from @constants
        ├─ Uses: Icons from @constants
        └─ Renders: Skills grid

     └─ Portfolio.jsx
        ├─ Uses: PROJECTS array from @constants
        ├─ Uses: Icons from @constants
        └─ Renders: Project showcase with filtering

     └─ Experience.jsx
        ├─ Uses: EXPERIENCES array from @constants
        ├─ Uses: Icons from @constants
        └─ Renders: Timeline layout

     └─ Contact.jsx
        ├─ Manages: Form state (name, email, message)
        ├─ Uses: Icons from @constants
        └─ Renders: Contact form

     └─ Footer.jsx
        ├─ Uses: Icons from @constants
        └─ Renders: Footer with social links

  5. Data Flow
     src/constants/constants.jsx (single source of truth)
     ├─ Icons → Used in ALL components
     ├─ PROJECTS → Used in Portfolio.jsx
     ├─ EXPERIENCES → Used in Experience.jsx
     └─ SKILLS → Used in Skills.jsx

  6. Styling
     src/styles/globals.css (imported in src/index.jsx)
     ├─ Tailwind CSS base styles
     ├─ Custom scrollbar
     ├─ Dark mode setup
     ├─ Font imports
     └─ Animation definitions
     
     tailwind.config.js (processes all className attributes)
     └─ Scans src/**/*.{jsx,js}
     └─ Finds all used Tailwind classes
     └─ Generates CSS for production

State Management:
═══════════════════════════════════════════════════════════════════════════════

  App.jsx manages:
    1. Theme state (dark/light)
       └─ Stored in localStorage
       └─ Applied to <html> element with 'dark' class
       └─ Affects all components via Tailwind dark: prefix

    2. ScrollUp visibility state
       └─ Tracks scroll position

  Port: 3000 (3001, 3002, etc. if in use)
  Hot Module Replacement: Enabled
  Startup Time: ~261 ms
  Features:

    - Shows errors in browser

Production Build (npm run build):
─────────────────────────────────────────────────────────────────────────────

  Input: src/ directory (all source files)
  Output: dist/ directory (optimized files)
  
  Process:
    1. Analyze all source files
    2. Tree-shake unused code
    3. Minify CSS and JavaScript
    4. Generate production bundle
    5. Create dist/index.html
    6. Create dist/assets/ with hashed filenames

  Build Results:
    - Time: ~2.45 seconds
    - HTML: 0.63 kB (0.42 kB gzip)
    - CSS: 30.07 kB (5.43 kB gzip)
    - JS: 223.94 kB (67.21 kB gzip)
    - Total: ~73 kB gzipped ✓ Optimized

Tailwind CSS Build Process:
─────────────────────────────────────────────────────────────────────────────

  1. Scans Content Paths
     tailwind.config.js:
     content: ['./index.html', './src/**/*.{jsx,js}']
     
     Finds all files matching pattern ✓

  2. Extracts Used Classes
     Searches for className attributes
     Finds all Tailwind class names
     
     Example: className="bg-white dark:bg-[#050505] text-gray-900"
     Extracts: bg-white, bg-[#050505], text-gray-900

  3. Generates CSS
     Creates CSS rules for all found classes
     Applies theme customization
     Applies dark mode rules

  4. Purges Unused Styles
     Removes any Tailwind classes NOT found in source
     Reduces CSS file size dramatically

  Result:
    - Before Fix: 7.07 kB CSS (styles missing!)
    - After Fix: 30.07 kB CSS (all styles included!) ✓
